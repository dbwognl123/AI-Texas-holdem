# AI Texas Hold'em

## 프로젝트 소개

**AI Texas Hold'em**은 AI 프롬프트를 활용하여 제작한 1인용 텍사스 홀덤 포커 게임 프로토타입입니다.

플레이어 1명과 AI 플레이어 5명이 한 테이블에서 게임을 진행하며, 텍사스 홀덤의 기본 흐름인 카드 배분, 블라인드, 베팅 라운드, 플랍, 턴, 리버, 쇼다운 과정을 구현하는 것을 목표로 했습니다.

현재 저장소는 Unity 전체 프로젝트 파일이 아니라, 게임의 핵심 로직과 UI 연결을 담당하는 C# 스크립트 중심으로 구성되어 있습니다.

---

## 개발 목적

이 프로젝트는 AI 프롬프트를 활용하여 게임 로직을 설계하고 구현하는 과정을 경험하기 위해 제작되었습니다.

단순히 코드를 생성하는 것에서 끝나는 것이 아니라, AI가 제안한 구조를 Unity 환경에 맞게 적용하고, 카드 게임 규칙을 코드로 분리하며, 실제 게임 흐름이 동작하도록 수정하는 데 초점을 두었습니다.

특히 텍사스 홀덤처럼 규칙과 상태 변화가 많은 게임을 기능 단위로 나누어 구현하는 연습을 목표로 했습니다.

## 주요 기능

### 1. 카드 시스템

52장의 카드를 ID 기반으로 관리합니다.

구현된 기능은 다음과 같습니다.

- 카드 ID 관리
- 카드 숫자 Rank 계산
- 카드 문양 Suit 계산
- 카드 문자열 출력
- 52장 덱 생성
- Fisher-Yates 방식 셔플
- 카드 드로우
- 번 카드 처리

카드는 `2c`, `As`, `Td`와 같은 형태로 표현됩니다.

---

### 2. 딜러 시스템

텍사스 홀덤의 카드 배분 순서를 구현했습니다.

진행 방식은 다음과 같습니다.

1. 각 플레이어에게 홀카드 2장 배분
2. 플랍 공개 전 번 카드 1장 처리
3. 플랍 카드 3장 공개
4. 턴 공개 전 번 카드 1장 처리
5. 턴 카드 1장 공개
6. 리버 공개 전 번 카드 1장 처리
7. 리버 카드 1장 공개

---

### 3. 핸드 족보 판정

플레이어의 홀카드 2장과 커뮤니티 카드 5장을 합친 7장의 카드 중 가장 강한 5장 조합을 찾아 족보를 판정합니다.

구현된 족보는 다음과 같습니다.

| 족보 | 설명 |
|---|---|
| High Card | 가장 높은 카드 |
| One Pair | 같은 숫자 2장 |
| Two Pair | 페어 2개 |
| Three of a Kind | 같은 숫자 3장 |
| Straight | 연속된 숫자 5장 |
| Flush | 같은 문양 5장 |
| Full House | 트리플 + 페어 |
| Four of a Kind | 같은 숫자 4장 |
| Straight Flush | 같은 문양의 연속된 숫자 5장 |

족보가 같을 경우 타이브레이커를 비교하여 승자를 결정합니다.  
완전히 같은 점수일 경우 공동 승자로 처리됩니다.

---

### 4. 베팅 시스템

텍사스 홀덤의 기본 베팅 흐름을 구현했습니다.

지원하는 액션은 다음과 같습니다.

| 액션 | 설명 |
|---|---|
| Fold | 현재 판을 포기 |
| Check | 추가 베팅 없이 넘김 |
| Call | 현재 베팅 금액에 맞춤 |
| Raise | 베팅 금액을 올림 |
| All-In | 보유 칩을 모두 베팅 |

스몰 블라인드와 빅 블라인드가 적용되며, 현재 베팅 금액에 따라 가능한 액션이 달라집니다.

---

### 5. AI 플레이어

AI 플레이어는 간단한 확률 기반 방식으로 행동합니다.

현재 AI는 정교한 포커 전략을 사용하지는 않지만, 게임 흐름 테스트를 위해 다음과 같은 행동을 수행합니다.

- 콜해야 할 금액이 있으면 Fold / Call / Raise 중 선택
- 콜할 금액이 없으면 Check / Raise 중 선택
- 일정 확률에 따라 행동 결정

---

### 6. UI 액션 시스템

플레이어는 Unity UI 버튼을 통해 행동을 선택할 수 있습니다.

구현된 UI 입력은 다음과 같습니다.

- Fold 버튼
- Check 버튼
- Call 버튼
- Raise 버튼
- All-In 버튼
- Raise 금액 입력창
- 현재 상황에서 가능한 버튼만 표시하는 기능

---

### 7. 카드 렌더링 시스템

카드 데이터를 실제 카드 이미지로 표시하기 위한 구조를 구현했습니다.

지원하는 방식은 다음과 같습니다.

- 카드 앞면 표시
- 카드 뒷면 표시
- 플레이어 홀카드 표시
- AI 카드 숨김 처리
- 커뮤니티 카드 표시
- SpriteRenderer 방식 지원
- Unity UI Image 방식 지원
